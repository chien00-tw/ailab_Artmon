校園美感精靈圖鑑系統說明

1. 離線即用：全部程式碼、SVG 角色圖騰與音效運算皆整合於單一檔案，無須持續連線網路。

2. 音效與觸覺：採用 Web Audio API 合成頻率音訊，支援平板手機的 Vibration API（觸覺震動回饋）。

3. 防轉傳作弊安全鎖：設備首次登入會計算專屬指紋鹽值（Device Hash），產出的 QR Code 格式如下：

AESTHETIC:{ELEMENT_ID}:{SEAT_NO}:{DEVICE_KEY}

各組若將網址截圖傳至外班，因設備 Key 與座號不符，系統將拒絕解鎖。
